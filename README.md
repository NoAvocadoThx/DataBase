# 同写意专家智库 MVP

内部使用的专家档案库：Excel / 会议资料导入 → AI 抽取 → 人工审核入库 → 按条件或自然语言找专家。

## 运行

```
pip install -r requirements.txt
python -m uvicorn app.main:app --reload        # 或双击 run.bat
```
打开 http://127.0.0.1:8000 ，默认账号 **admin / admin123**，登录后点右上角用户名进“我的账户”修改密码。

`run.bat` 已设好本机开发所需的环境变量。用命令行启动时需要：

```
set ALLOW_INSECURE_SECRET=1   # 会话密钥每次随机（生产必须改用 .env 里的 SECRET_KEY）
set SECURE_COOKIE=0           # 本机是 http，不关掉登录不上
```

环境变量（见 `.env.example`）：
- `SECRET_KEY`：会话签名密钥，**生产必填**（`openssl rand -hex 32`，至少 32 字符）。缺失或过短会拒绝启动——防止用可预测的密钥被伪造管理员会话
- `SECURE_COOKIE`：默认 `1`（Cookie 只在 HTTPS 下发送）。仅无 HTTPS 的演示环境设 `0`
- `LLM_API_KEY` / `LLM_URL` / `LLM_MODEL`：OpenAI 兼容的大模型接口（默认 DeepSeek）。不设则资料抽取走规则、检索走关键词，功能完整可用

## 功能

| 模块 | 说明 | 权限 |
|---|---|---|
| 专家列表 / 详情 | 多关键词(AND)、单位、职务、方向、多标签(AND)、有无合作 组合筛选，排序，每页 50 分页；一万条数据毫秒级 | 所有人（实习生手机/邮箱/微信脱敏，看不到备注） |
| 新增 / 编辑专家 | 表单录入，标签自动补全 | 策划、管理员 |
| 资料录入 | 上传 PDF / Word / PPT / TXT → 抽取候选专家 → 审核页逐条确认 → 入库（保存来源文件与原文片段，可同时登记为某会议的合作记录） | 策划、管理员 |
| Excel 导入 / 导出 | 模板见 `sample/专家导入模板示例.xlsx` | 管理员 |
| 疑似重复 | 同名专家自动进队列；一键合并（补空字段、标签并集、合作历史迁移）或标记不同人 | 管理员 |
| 找专家 | 自然语言 → 拆条件 → 打分排序 → 每位专家附推荐依据 | 所有人 |
| AI 助手 | `/chat` 对话式问库：模型通过工具调用真去查专家 / 会议 / 统计，流式回复，引用的专家带 `/expert/{id}` 链接并逐个核对真伪；与专家库无关的问题在服务端直接拒答、不发给大模型；多轮上下文只存在浏览器里，刷新即清空 | 所有人 |
| AI 对话存档 | `/chat-log` 每次提问和 AI 完整回答（含用了哪些工具、引用了哪些专家、token 与花费）；可按人 / 日期 / 关键词筛选 | **仅管理员** |
| DeepSeek 用量 | `/chat-usage` 今日 / 本月 / 累计的调用次数、token、估算花费、缓存命中率，按人排名和近 14 天趋势 | **仅管理员** |
| 重点关注 | 专家分级：核心 / 重点 / 一般 / 不合作 + 关注说明；`/focus` 按分级分栏；列表页可按分级筛选 | 策划、管理员（所有人可看） |
| 专家分组 | 自建名单（如「2026 大会候选」），公开组全团队可见、私有组仅自己可见；一个专家可属多个分组 | 策划、管理员（实习生只读公开组） |
| 会议日历 | 会议独立成表（名称/日期/地点/状态），列表与按年份两种视图；会议详情看全部参会专家及其角色和报告主题；改会议名自动同步所有合作记录 | 策划、管理员（所有人可看） |
| 用户管理 | 三级角色 admin / planner / intern | 管理员 |
| 修改历史 | 每位专家的字段级改动记录（谁、何时、旧值→新值）；全局操作历史按操作人 / 类型 / 专家 / 日期筛选 + 分页 | 策划、管理员 |
| 回收站 | 删除/被合并的专家可恢复；彻底删除需二次确认，历史仍保留 | 管理员 |

去重规则：**姓名 + 单位**完全一致视为同一人（更新），仅同名进疑似重复。

AI 安全：发送给大模型前，手机 / 邮箱 / 微信号已正则打码；联系方式在本地用规则抽取。AI 结果一律进审核页，不直接写库。
AI 助手的工具结果走字段白名单（手机 / 邮箱 / 微信 / 内部备注 / 关注说明 / 录入原文一律不出境），出境前再整体打一次码；每次提问写访问日志，问答全文另存进仅管理员可见的对话存档。未配置 `LLM_API_KEY` 时对话框给出提示并引导去「找专家」，不报错。

> **录入规范**：机密内容请写在专家的「内部备注」里，**不要写进「简介」**。备注永不出境；简介会（脱敏后）发送给大模型用于判断匹配度。

AI 防编造：回答里出现的每个 `/expert/{id}` 都要在本轮工具结果里真实出现过，对不上的会被摘掉链接、当场标注"库中无此记录"，并记进对话存档供事后统计。

AI 话题限定：这是专家库助手，不是通用聊天入口。写代码 / 翻译 / 文案 / 闲聊 / 时事这类问题在**发给 DeepSeek 之前**就被规则拒答（零成本），规则只在"一个领域词都没有"时才生效，宁可放过也不误拒。

AI 限流与成本：`app/chat.py` 顶部集中定义 `RATE_LIMITS`（管理员不限 / 策划 30 次每分钟、200 次每天 / 实习生 10 次每分钟、60 次每天）和三个单价常量（缓存命中输入、未命中输入、输出，元每百万 token，**以 DeepSeek 官网当日价为准**）。每次调用都带 `stream_options.include_usage` 取回真实 token 数，多轮工具调用累加后入库。

数据保密：三级角色 + 敏感字段脱敏（含"录入原文"）、签名会话 Cookie（HttpOnly/Secure/SameSite，改角色或改密码后旧会话立即失效）、登录限速、导出留痕、软删除回收站、每日备份 700 权限。详见 `DEPLOY.md` 末尾的安全设计说明。

## 部署到云服务器

见 `DEPLOY.md`：分演示环境（IP + HTTP，只放假数据，10 分钟）和正式环境（域名 + HTTPS，真实数据）两条路径，含上线检查清单和给企业 IT 的安全设计说明。

## 备份

`python scripts/backup.py` 把数据库和上传文件复制到 `backups/日期/`，保留 30 天。加到 Windows 计划任务或 cron 每日执行。

## 压测数据

`python scripts/seed_demo.py 10000` 生成一万条虚构专家（含标签、合作记录）用于体验性能。

## 测试

```
python -m pytest tests -q
```
- `tests/test_core.py` 单元测试（导入去重、合并、脱敏、抽取、检索排序）
- `tests/test_acceptance.py` 端到端验收（登录 → 导入 → 重复合并 → 权限 → 上传 PDF 审核入库 → 自然语言检索 → 导出 → 编辑删除 → 修改历史/回收站 → 分面筛选 → 表头排序）
- `tests/test_security.py` 安全回归（伪造会话、越权、脱敏绕过、开放重定向、登录限速、导出审计、大模型脱敏、部署配置）
- `tests/test_chat.py` AI 对话（未配置降级、外发脱敏、工具调用查库、防编造校验、话题限定、分角色限流、token 用量与成本、对话存档与管理员权限、访问留痕、上下文截断、网络异常兜底；大模型调用全部 mock，不产生费用）

共 124 项。
